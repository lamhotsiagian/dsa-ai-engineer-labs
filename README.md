# DSA for AI & ML Engineers — Labs, Practice UI & Test Suite

The companion laboratory repository for *DSA for AI & ML Engineers: From Data Structures to Scalable AI Systems*.

---

## 📂 Repository Structure

- `dsa_labs/`: Canonical module implementations and algorithmic solutions covering Chapters 01 through 33 (including the complete NeetCode 150 companion across 18 domains).
- `tests/`: Automated test suite (167 tests) validating all data structures, ML primitives, inference caches, and LeetCode solutions.
- `dsa-practice-ui/`: Next.js & Monaco Editor interactive LeetCode-style web platform with live Python compilation, testcase runner, and adaptive challenge timers.

---

## 🧪 Running the Unit Tests

Ensure Python 3.10+ is installed:

```bash
# Run the complete test suite (167 tests across 33 chapters)
pytest
```

---

## 💻 Running the Interactive Practice UI

```bash
cd dsa-practice-ui
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to practice coding and testing your solutions interactively.
